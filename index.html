Can't start the graphics engine

  • Try safe graphics mode first: it uses far less of the GPU (no antialiasing pass, no depth of field or motion blur, 1× pixel ratio).
  • If a setting you changed causes it, reset saved settings (your saved presets are kept).
  • After a GPU driver hang, Windows sometimes keeps the driver in a bad state: restart the computer, and update the graphics driver.
  • Open chrome://gpu: "WebGL" and "WebGL2" should say "Hardware accelerated".
